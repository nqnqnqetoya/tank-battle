# ТАНКОВЫЙ БОЙ 🎮

2D танковая аркада на HTML5 Canvas. Уничтожай врагов, прокачивай танк, покупай скины и снаряды — и сразись с бесконечными волнами!

**▶️ GitHub Pages:** https://nqnqnqetoya.github.io/tank-battle/

---

## ✨ Особенности

- **Бесконечный геймплей** — враги становятся сильнее с каждым уровнем
- **Система уровней** — каждые 1000 очков выбор одного из трёх улучшений
- **Магазин перков** — аптечка, броня, ускоритель, автоматическая перезарядка
- **Типы снарядов** — стандартный, бронебойный (×2 урон), взрывной (AoE), быстрый (+50% скорости)
- **Магазин скинов** — зелёный, серый, пустынный, морской (покупаются за монеты)
- **Монеты** — выпадают с врагов (1–3 за убийство), сохраняются в localStorage
- **Новостная строка** — абсурдные военные сводки внизу экрана
- **Постепенное усложнение** — враги получают +1 HP, +8 скорости, чаще стреляют с каждым уровнем
- **Донат-страница** — чисто для атмосферы
- **Спрайты** — Kenney Tanks (CC0)

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| **WASD** / Стрелки | Передвижение танка |
| **Мышь** | Прицеливание |
| **ЛКМ** | Стрельба |
| **Пробел** | Рестарт после поражения |

## 💻 Локальный запуск

Просто открой `index.html` в браузере — никаких серверов не нужно.

### Python
```bash
python -m http.server 8080
```

### VS Code
ПКМ на `index.html` → Open with Live Server
